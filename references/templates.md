## design.md

```markdown
# <Название дизайна>

> Дизайн <DDD> — создан <YYYY-MM-DD>

## Проблема

<Что хотим получить, зачем и для кого>

## Цели

<Конкретные, измеримые результаты>

## Не-цели

<Явно за пределами скоупа>

## Анти-цели

<Чего результат не должен делать или ухудшать>

## Ограничения

<Жёсткие требования: версии, контракты, совместимость, сроки — с точными значениями>

## Подходы

<2–3 способа, что каждый даёт и чего стоит; какой выбран и почему>

## Дизайн

<Решения о том, как строить, принятые вместе с пользователем: архитектура, потоки
данных, ключевые решения. Решения, которые агент принял сам по итогам builder check,
пометить «решение агента»>

## Оставлено исполнителю

<Что исполнитель решает сам; если ничего — «Нет»>

## Открытые вопросы

<Нерешённые пункты; если их нет — «Нет»>
```

Короткий дизайн небольшой правки — те же разделы по строке-две. Раздел, которому
нечего сказать, — «Нет».

## Дополнения файла фазы

Файл `phase-<DDD>-<PP>.md` — это план по шаблону writing-plans. Заголовок плана заменить
на `# Фаза <PP>: <Название фазы>`, между шапкой writing-plans и первой задачей вставить:

```markdown
> Фаза <PP> из <всего фаз>

## Пререквизиты

<Что должно быть сделано до фазы: ссылка на phase-<DDD>-<PP-1>.md или «Нет» для фазы 00>

## Критерии завершения фазы

<Проверяемое условие: команда и ожидаемый вывод>
```

## progress.md

Шапка — создаётся на шаге 1:

```markdown
# Прогресс — <Название дизайна>

> Дизайн <DDD> | Обновлено: <YYYY-MM-DD>
```

Сводка и задачи — добавляются на шаге 2 под шапку. Одна строка сводки и один
раздел задач на каждую фазу; у плана без фаз — одна фаза `00` с названием «Основная».

```markdown
## Сводка

| Фаза | Всего | Готово | Статус |
|------|-------|--------|--------|
| 00   | <N>   | 0      | 🔲 Не начата |

## Задачи

### Фаза 00: <Название фазы или «Основная»>

- [ ] `T<DDD>-00-01` — <Краткое описание задачи>
- [ ] `T<DDD>-00-02` — <Краткое описание задачи>
```

Правило пересчёта строки сводки после отметки задачи — `Готово` = число `[x]`
в разделе фазы, `Статус`:

| Готово | Статус |
|--------|--------|
| 0 | 🔲 Не начата |
| больше 0 и меньше `Всего` | 🔄 В процессе |
| равно `Всего` | ✅ Завершена |

При каждом изменении `progress.md` обновить дату в строке «Обновлено».
